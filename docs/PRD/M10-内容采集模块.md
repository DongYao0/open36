# M10 - 内容采集模块 PRD

## 模块概述

**模块名称**：内容采集模块（CrawlerService）
**模块编号**：M10
**优先级**：P2
**技术栈**：Python 3.11+ + FastAPI + Crawl4AI
**版本**：2.2.0-beta

### 业务目标

1. **内容采集**：从外部网站爬取技术文章、教程等内容
2. **内容整理**：通过 AI 对爬取内容进行摘要、分类、质量评估
3. **日报生成**：定时生成技术日报，自动发布到论坛

### 架构定位

```
CrawlerService (Python FastAPI)
├── 爬取引擎 (Crawl4AI)
├── AI 整理 (OpenAI-compatible LLM)
├── 定时调度 (APScheduler)
└── API 接口 (/api/v1/crawl, /api/v1/digest)
       │
       ▼
  Forum Service :8003 (发布帖子)
  File Service :8007 (存储图片)
```

## 功能能力

### 1. 爬取能力

| 功能 | 说明 |
|------|------|
| 单页爬取 | 输入 URL，输出 Markdown + 标题 + 元数据 |
| 深度爬取 | BFS 遍历同域页面，支持深度和页数上限 |
| 关键词搜索 | Bing/Sogou/Baidu/Google 搜索入口，自动降级 |
| RSS/Atom | 解析 feed，按 freshness 过滤后逐篇爬取 |
| 混合来源 | 日报中支持 keyword/url/rss 混合来源 |

### 2. 内容处理

| 功能 | 说明 |
|------|------|
| 质量评估 | 来源可信度、内容长度、页面类型、spam 信号 |
| 去重 | URL 规范化、SimHash、历史 fingerprint |
| 来源效能 | 记录成功率、质量均值、失败原因，跳过 dead source |
| SSRF 防护 | 限制内网地址和危险 URL |

### 3. AI 与日报

| 功能 | 说明 |
|------|------|
| AI 整理 | tech_summary、tutorial、comparison、knowledge_report、daily_digest |
| 定时日报 | 工作日定时生成，管理端手动触发 |
| 结构化保存 | digest_section、digest_item |
| 质量评分 | 趋势记录、弱点建议、优化记录查询 |

## 服务模式

| 模式 | 说明 |
|------|------|
| Standalone | 独立运行，自带数据库和调度 |
| Integrated | 作为内部服务被其他服务调用 |
