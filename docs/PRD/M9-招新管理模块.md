# M9 - 招新管理模块 PRD

## 模块概述

**模块名称**：招新管理模块
**模块编号**：M9
**优先级**：P1
**目标用户**：社团管理员 + 申请者
**技术栈**：Spring Boot 3 + Sa-Token + JPA + PostgreSQL

### 业务目标

1. **报名管理**：收集和审核招新申请
2. **面试管理**：记录面试轮次、评分、结果
3. **作业分发**：管理员创建作业任务，分配给申请者
4. **作业收集**：申请者提交作业，管理员查看和管理

### 架构定位

```
Open436-Admin :3001
       │
       ▼
  Enrollment :8084  ──→  PostgreSQL :55400
  (Spring Boot)      ──→  Redis :6380 (Sa-Token)
```

## 功能需求

### 1. 报名管理

#### 1.1 提交申请

| 项目 | 说明 |
|------|------|
| 接口 | `POST /api/enrollment/apply` |
| 鉴权 | `@SaCheckLogin` |
| 输入 | selfIntro, skills |

业务规则：
- 用户只能提交一次申请
- 提交后状态为 `pending`
- 自动关联当前登录用户的 authUserId

#### 1.2 申请列表

| 项目 | 说明 |
|------|------|
| 接口 | `GET /api/enrollment/?page=1&size=10&status=pending&keyword=张三` |
| 鉴权 | `@SaCheckRole("admin")` |
| 输出 | 分页列表，支持状态筛选和关键词搜索 |

#### 1.3 审核申请

| 项目 | 说明 |
|------|------|
| 接口 | `PUT /api/enrollment/{id}/review` |
| 鉴权 | `@SaCheckRole("admin")` |
| 输入 | `status`（approved/rejected）, `reason`（可选） |

#### 1.4 批量审核

| 项目 | 说明 |
|------|------|
| 接口 | `POST /api/enrollment/batch-review` |
| 鉴权 | `@SaCheckRole("admin")` |
| 输入 | `ids`（ID数组）, `status` |

#### 1.5 统计数据

| 项目 | 说明 |
|------|------|
| 接口 | `GET /api/enrollment/statistics` |
| 鉴权 | `@SaCheckRole("admin")` |
| 输出 | total, pending, approved, rejected, approvalRate |

### 2. 面试管理

#### 2.1 面试列表

| 项目 | 说明 |
|------|------|
| 接口 | `GET /api/interview/?enrollmentId=1` |
| 鉴权 | `@SaCheckRole("admin")` |
| 输出 | 按轮次分组的面试记录列表 |

#### 2.2 录入面试记录

| 项目 | 说明 |
|------|------|
| 接口 | `POST /api/interview/record` |
| 鉴权 | `@SaCheckRole("admin")` |
| 输入 | enrollmentId, round, score, evaluator, feedback, result(pass/fail/pending) |

业务规则：
- 同一申请者同一轮次只能有一条记录
- 支持多轮面试

#### 2.3 更新面试状态

| 项目 | 说明 |
|------|------|
| 接口 | `PUT /api/interview/{id}/status` |
| 鉴权 | `@SaCheckRole("admin")` |
| 输入 | result(pass/fail/pending), feedback |

#### 2.4 获取申请者面试记录

| 项目 | 说明 |
|------|------|
| 接口 | `GET /api/interview/{enrollmentId}` |
| 鉴权 | `@SaCheckRole("admin")` |
| 输出 | 该申请者的所有面试轮次记录 |

#### 2.5 面试统计

| 项目 | 说明 |
|------|------|
| 接口 | `GET /api/interview/statistics` |
| 鉴权 | `@SaCheckRole("admin")` |
| 输出 | 总面试数、各轮次通过率 |

### 3. 作业分发

#### 3.1 创建作业

| 项目 | 说明 |
|------|------|
| 接口 | `POST /api/assignment/` |
| 鉴权 | `@SaCheckRole("admin")` |

| 鉴权 | `@SaCheckRole("admin")` |

|------|------|
| 接口 | `POST /api/assignment/{id}/allocate` |
| 鉴权 | `@SaCheckRole("admin")` |

#### 3.4 移除分配

| 项目 | 说明 |
|------|------|
| 接口 | `DELETE /api/assignment/{id}/allocate/{studentId}` |
| 鉴权 | `@SaCheckRole("admin")` |

#### 3.5 查看作业成员

| 项目 | 说明 |
|------|------|
| 接口 | `GET /api/assignment/{id}/members` |
| 鉴权 | `@SaCheckRole("admin")` |
| 输出 | 已分配学生列表 |

### 4. 作业收集

#### 4.1 查看我的作业（申请者端）

| 项目 | 说明 |
|------|------|
| 接口 | `GET /api/assignment/my` |
| 鉴权 | `@SaCheckLogin` |
| 输出 | 当前用户被分配的作业列表 |

#### 4.2 提交作业（申请者端）

| 项目 | 说明 |
|------|------|
| 接口 | `POST /api/assignment/my/{assignmentId}/submit` |
| 鉴权 | `@SaCheckLogin` |
| 输入 | content（作业内容） |

#### 4.3 查看提交列表（管理员端）

| 项目 | 说明 |
|------|------|
| 接口 | `GET /api/assignment/{id}/submissions` |
| 鉴权 | `@SaCheckRole("admin")` |
| 输出 | 该作业的所有提交记录 |

#### 4.4 提醒未提交者

| 项目 | 说明 |
|------|------|
| 接口 | `POST /api/assignment/submissions/{submissionId}/remind` |
| 鉴权 | `@SaCheckRole("admin")` |

## 数据模型

### 实体清单

| 实体 | 说明 |
|------|------|
| `EnrollmentApplication` | 招新申请（关联 authUserId） |
| `Interview` | 面试记录（多轮次） |
| `Assignment` | 作业任务 |
| `AssignmentAllocation` | 作业分配（学生-作业关联） |
| `AssignmentSubmission` | 作业提交 |
