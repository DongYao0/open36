# 事件：首页 404（landing/ 目录为空）

**时间**：2026-09-14 ~13:25 (UTC+8)
**影响**：public-web 反代 `/usr/share/nginx/html/landing/` 返回 403（目录浏览被禁且无 index.html）
**根因**：tarfile 重打包迭代方案在写目录条目时丢失 type 字段（默认 type 0=REGTYPE 文件），导致远端 `tar -xzf` 把目录项当文件解但无内容，覆盖 mount 源 `/home/sunrise-ssh/open436/deploy/prod/public-web/dist/landing/` 为只有 index.html 的非目录状态；mount `ro` + 容器缓存使 `ls` 在已挂载进程内仍展示旧内容（误导诊断）。
**修复**：物理重启 public-web 容器→ 重新解析 bind mount → 57 个 assets + index.html 正常可见→ 移除 8080 LAN 临时端口（`compose up -d public-web` 退掉 overlay）。
**教训**：tarfile 重打包目录条目必须显式 `TarInfo.type = DIRTYPE`；mount readonly + 缓存会让 docker exec 的 ls 显示陈旧内容，**用 curl 或外部网络验证为权威**。
